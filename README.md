# 📄 AI-Powered PDF Merger

A Python-based utility that leverages Artificial Intelligence to intelligently combine, organize, and process PDF documents. Designed as an educational project to demonstrate seamless integration between modern AI models and file automation.

---

## ✨ Features

- **Intelligent Page Merging:** Combines multiple PDF files into a single, cohesive document.
- **AI-Assisted Processing:** Analyzes and categorizes PDF content for smart ordering or summary generation.
- **Simple & Intuitive Interface:** Clean command-line interface (CLI) / execution flow for quick file merging.
- **Fast Execution:** Optimized memory handling for merging large multi-page PDF documents.

---

## 🛠️ Built With

* **Python 3.x** - Core programming language
* **PyPDF2 / pypdf** - PDF manipulation and extraction library
* **AI Model Integration** - OpenAI API / Gemini API *(adjust based on your setup)*
